# Historical project material

These are distinct source snapshots and development assets, preserved so useful work is not lost. The active app lives at the repository root. Do not assume a later filesystem timestamp means that an archived UI or transport supersedes the active implementation.

See [source provenance](../docs/PROVENANCE.md) for each folder's origin and the publication cleanup. Each archived app has its own manifest and build assumptions. Old status documents can contradict later evidence. No automatic merge between the React/Swift and JavaScript/Objective-C implementations has been performed.

`releases/` contains original historical Intel ZIPs, not newly validated releases. `promo/` is historical promotional material and does not establish that every depicted function works on hardware. Promo-generation scripts may still need local output paths supplied in place of `<HOME>`.
